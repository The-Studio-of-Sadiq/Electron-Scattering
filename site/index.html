Dirac Partial-Wave Elastic Scattering in Your Browser

Dirac partial-wave elastic scattering of electrons and positrons by atoms, ions and molecules, running the official ELSEPA 2021 Fortran compiled to WebAssembly, right in the browser, offline-capable PWA.

Capabilities

Comprehensive Relativistic Physics Suite

A state-of-the-art computational platform mapping every parameter of the official ELSEPA 2021 Fortran code to modern interactive controls.

Atomic Workbench (ELSCATA)

Simulate elements $Z = 1$ to $103$ selected from an interactive periodic table. Supports electron ($e^-$) and positron ($e^+$) projectiles at energies $E \ge 10\text{ eV}$. Configure nuclear charge models (point, uniform sphere, Fermi, Helm) with atomic weight (ATWGHT), nuclear radius (NUCRAD), and skin (NUCSKN) overrides. Full exchange, polarization, and absorption potential controls.

Z = 1–103 Dirac–Fock Muffin-tin Polarization
New in v2.0

Radial Electron Density Editor

A visual interactive editor for radial electron densities $\rho(r)$. Load ELSEPA Dirac–Fock, DHFS, TFD, or TFM densities; drag curve control points, normalize to bound electron count $Z - q$, ionize or add electrons (including negative ions $q < 0$), scale radially, truncate, smooth, or mix. Inspect automated metrics ($N$, $\langle r \rangle$, $R_{50}$, $R_{90}$) and export directly to ELSEPA .den format or inject into simulation.

Drag-Edit Negative Ions Normalization .den Export

Molecular Mode (ELSCATM)

Execute ELSEPA's molecular program using the independent-atom model (IAM) with coherent addition of atomic scattering amplitudes and orientation averaging. Built-in presets for $\text{H}_2\text{O}$, $\text{CO}_2$, $\text{CH}_4$, $\text{N}_2$, $\text{C}_6\text{H}_6$, and $\text{UF}_6$. Freely add, remove, and edit 3D atomic coordinates in Å. Computes coherent and incoherent DCS and cross sections.

ELSCATM 3D Cartesian Coherent DCS IAM

Energy Sweeps and Custom Grids

Compute total elastic ($\sigma_{\text{el}}$), first transport ($\sigma_1$), and second transport ($\sigma_2$) cross sections across energy spectrums plotted on interactive log–log axes. Choose between standard 16-point grids (10 eV to 1 MeV), logarithmic ranges ($1 \le N \le 100$ points, $10\text{ eV} \le E \le 10^9\text{ eV}$), or arbitrary custom lists with scientific notation (1e3, 2.5E4).

Log–Log Axes Transport $\sigma_1, \sigma_2$ Custom Energy Grids

User-Supplied Densities (MELEC 5)

Upload custom radial electron density tables in .den, .dat, .txt, or .csv format ($5 \le N \le 999$ points). Automatic trapezoidal normalization verification ensures $4\pi \int_0^\infty \rho(r)r^2 dr = Z - q$ with a 1% tolerance warning. Executed inside isolated temporary workspaces on the server and fresh in-memory filesystems in WebAssembly.

MELEC 5 Charge Check Isolated FS

Custom Angular Grids and Integration

Resample calculated differential cross sections, spin-rotation functions $T(\theta)$ and $U(\theta)$, and the Sherman function $S(\theta)$ onto custom user-defined angular steps. Calculate numerical cross-section integrals over customized angular sub-ranges alongside full $0^\circ$ to $180^\circ$ integration.

Resampling Partial Integrals Sherman S($\theta$)

Saved Runs and Comparative Analysis

Save complete simulation parameters and calculated results to browser localStorage. Overlay up to 6 saved runs simultaneously on unified charts, or inspect fine-grained percentage differences between any 2 calculations. Export runs as JSON, clone saved parameters straight back to the workbench, and run batch element sweeps.

6-Run Overlay % Difference Batch Series JSON Export

Experimental Dataset Overlay

Upload laboratory measurement files in .dat, .csv, or .txt format (up to 5 MB). The system parses angle and differential cross section pairs and renders them as discrete scatter points directly over theoretical ELSEPA curves for immediate visual validation.

5 MB Upload Data Overlay Literature Benchmarks

Offline PWA and Dual Theme

Engineered as an installable Progressive Web App with service-worker precaching of all UI assets, WebAssembly binaries, and 206 atomic database tables. Functions entirely offline on laptops, tablets, and mobile devices. Full scientific dark and light themes with system preference detection and persistence.

100% Offline PWA Ready Dark / Light UI Zero Setup

Dual Architecture: WebAssembly and Server

Zero-install in-browser WebAssembly execution in dedicated module Web Workers is the primary engine. An optional Node.js/Express server is available for researchers desiring native gfortran compilation. Both engines run the same Fortran 90 sources, and automated CI parity tests check that their results agree to within a relative tolerance of 10−5.

Engineering

How It Works: Compilation & Execution Architecture

From the authors' pristine 2021 Fortran 90 source code to high-speed WebAssembly executing inside isolated browser Web Workers.

Compilation & Runtime Pipeline

1
Official ELSEPA 2021 Official Fortran 90 package (package elsepa-2020) and RADIAL wave library by Salvat, Jablonski, and Powell. Original author files remain completely unmodified.
2
Build-Time Extensions wasm/patch-elsepa.mjs prepares documented keyword extensions (overriding ATWGHT, NUCRAD, NUCSKN, VPOLB, negative ions) into a staging directory.
3
f90to77 & f2c Translation wasm/f90to77.py and f77fix.py reorder non-executable statements to strict Fortran 77, and netlib f2c translates Fortran routines to C.
4
Emscripten WebAssembly Compiled with emcc -O3 into elsepa.wasm (270 KB) and elsepa.data (4 MB containing 206 atomic Dirac–Fock density and screening tables).
5
Browser Web Worker Executes in a dedicated module Web Worker with a clean virtual filesystem per run. Client localApiFallback.ts transparently intercepts /api/* requests without requiring any backend.

Validation Scope & Reference Comparison

The automated test suite in wasm/parity.test.ts runs under continuous integration (.github/workflows/elsepa-parity.yml). Thirteen benchmark cases compare the WebAssembly output directly against official reference output tables in validations/ generated with official ELSEPA 2021, including the authors' official 2021 publication test decks (elscata.in and h2o.in). Eight additional cases test newly added model options (positive ions, muffin-tin models, Helm nuclear distribution, TFM, TFD, DHFS densities, and user-supplied densities using Au z_079.den).

Unit test suites (wasm/features.test.ts, density.test.ts, overrides.test.ts) verify grid algorithms, normalization integrals, and parameter overrides, while wasm/browser.test.ts validates browser-only execution and offline service worker operation via headless Chrome DevTools Protocol.

Deployment

Get Started in Seconds

Choose the execution model that best fits your scientific workflow: immediate in-browser use, local workstation development, or pre-configured Docker containers.

Method 1

Run in Browser

Zero install, runs immediately via WebAssembly on any modern browser.

Access the complete ELSEPA 2021 engine directly from your browser. Once loaded, the application installs as a Progressive Web App (PWA) and performs full relativistic calculations completely offline.

✓ Zero installation required ✓ 100% client-side WebAssembly ✓ Offline PWA operation
Launch Web Application
Method 2

Run Locally with Node

Clone the repository and run the local development server.

Requires Node.js ^20.19.0 || >=22.12.0. If gfortran is found on your PATH, the local server automatically compiles and runs ELSEPA natively; otherwise it runs via WebAssembly.

bash 
git clone https://github.com/The-Studio-of-Sadiq/Electron-Scattering.git
cd Electron-Scattering
npm ci
npm run dev

Then open http://localhost:3000 in your browser.

Method 3

Run with Docker

Pre-packaged container with gfortran native compilation built in.

Run the multi-stage production container based on node:20-slim with native gfortran pre-compiled executables and static assets bundled.

bash 
docker run -p 3000:3000 ghcr.io/the-studio-of-sadiq/electron-scattering:latest

Access the running service on port 3000.
